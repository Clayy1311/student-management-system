# Student Management System

This is a web-based Student Management System that allows for the management of student data with user authentication, JWT-based authentication, and a user-friendly interface. The project is built using **Laravel** for the backend and **Flutter** for the mobile frontend.

## Features

- **User Authentication**: Includes both regular users and admin users.
- **JWT Authentication**: Secure authentication using JSON Web Tokens.
- **CRUD Operations**: Create, read, update, and delete student data.
- **Admin Dashboard**: Admin can view, manage students, and perform actions like adding or deleting student records.
- **Frontend and Backend**: The project is split into two separate stacks: Laravel (backend) and Flutter (mobile frontend).
- **Responsive**: The system is designed to be responsive, ensuring it works well on both desktop and mobile devices.

## Tech Stack

- **Backend**: Laravel, MySQL
- **Frontend**: Flutter
- **Authentication**: JWT
- **Version Control**: Git & GitHub
